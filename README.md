# XGM Studio

An asset editor for Angry Birds Go with support for 3D models, textures, and animations. Preview and convert assets, edit projects, and export modified PAKs or APKs. Game files are not included.

![XGM Studio editor](https://github.com/kaperkad/XGM-Studio/blob/main/editor.jpg?raw=true)

## Credits

`ExientXGSTools.py` was created by **It's Going To Be About Pirate (igtbap)**. Find the original [Discord post](https://discord.com/channels/502223141179883540/502230440921268225/1494293490471927818) and [download the script](https://drive.google.com/file/d/1VGmBy-If-bVgyjovP7pXcwllrvwvV4Ia/view?usp=drive_link). XGM Studio uses it to extract assets from PAK archives during import, read asset catalogs, and convert binary XML into readable XML.
